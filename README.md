# 📘 SERS 光谱分析系统帮助文档

## 🛠️ 环境配置

请按顺序执行以下指令以完成环境搭建：

```bash
#注意：本项目的训练、测试数据集未公开
# 1. 创建环境 (Python 3.9)
conda create -n sers python=3.9 -y

# 2. 激活环境
conda activate sers

# 3. 安装依赖
pip install -r requirements.txt

```

## 📂 系统架构与功能说明

| 文件路径 | 功能描述 | 备注 |
| :--- | :--- | :--- |
| `src/draw_origin_data.py` | **查看原始数据** | 可直接运行。绘制原始数据集的光谱图。 |
| `src/draw_train_data.py` | **查看训练数据** | 可直接运行。绘制预处理后的训练集（纯净物）光谱图。 |
| `src/main.py` | **主程序** | 可直接运行。执行模型训练或测试。 |
| `logs/` | **日志目录** | 存放运行日志。 |
| `输出/` | **结果输出** | 存放模型预测结果和分析图表。 |

## ⚙️ 配置文件参数详解 (`config.py`)

所有主要的可调参数均位于 `SERS/config.py` 中。
> **提示**：修改参数后，直接运行 `main.py` 即可生效。

### 1. 物理与数据参数
| 参数名 | 默认值 | 含义与建议 |
| :--- | :--- | :--- |
| **INPUT_LEN** | `1201` | **光谱长度**。<br>对应 (600~1800 cm⁻¹) 的数据点数。若更换光谱仪导致长度变化，需修改此值。 |
| **WAVELENGTH_RANGE** | `(600, 1800)` | **光谱范围**。<br>仅用于绘图时的坐标轴显示范围。 |
| **CLASS_MAP** | `{'CV': 0...}` | **类别映射表**。<br>⚠️ **绝对不要修改**。如果原始数据集类别发生变更，请联系开发者修改代码。 |

### 2. 训练超参数 (核心)
| 参数名 | 默认值 | 含义与建议 |
| :--- | :--- | :--- |
| **SEED** | `42` | **随机种子**。固定它以保证每次训练结果可复现。 |
| **BATCH_SIZE** | `32` | **批次大小**。<br>• 显存/内存不足时：调小 (16 或 8)<br>• 显存充足时：调大 (64) 以加快训练。 |
| **EPOCHS** | `40` | **训练轮数**。如果 Loss 还在下降但训练停了，可适当增加此值。 |
| **BASE_LR** | `0.0001` | **基础学习率**。<br>• Loss 震荡不收敛 -> 调小<br>• 学习太慢 -> 调大 |
| **MASK_LR_SCALE** | `40.0` | **掩码学习率倍率**。<br>专用于 `SpectralMask` 层。倍率越高，模型寻找特征波长越激进。 |
| **L1_LAMBDA** | `0.0001` | **稀疏正则化系数**。<br>• 值越大：选出的特征波长越少（更稀疏）<br>• 值越小：保留的波段越多 |

### 3. 流程控制开关
| 参数名 | 默认值 | 含义 |
| :--- | :--- | :--- |
| **IS_GENERATE_TRAIN_DATA** | `True` | **是否重新生成数据**。<br>• `True`: 此时若修改了数据增强比例或更新了原始数据，会重新处理。<br>• `False`: 跳过数据处理（仅调参时推荐），节省时间。 |
| **IS_RETRAIN** | `True` | **是否重新训练**。<br>• `True`: 从头开始训练模型。<br>• `False`: 加载 `model/sers_model.pth` 直接进行测试评估。 |
| **IS_USE_SINGLE_SUBSTANCE** | `True` | **是否包含纯净物**。<br>通常建议开启，保证模型学习到纯净物的特征。 |

### 4. 数据增强配置 (`MIX_CONFIG`)
控制混合样本的生成比例。
格式为：`(A物质份数, B物质份数, 生成数量)`

**示例：** `(1, 9, 10)`
* **混合比例**：10% A物质 + 90% B物质
* **生成数量**：10 条数据

> **💡 调优建议**：如果发现模型对某种低浓度混合物识别效果差，可以在这里增加对应的生成数量。

### 5. 评估与阈值
| 参数名 | 默认值 | 含义 |
| :--- | :--- | :--- |
| **PRED_THRESHOLD** | `0.05` | **预测阈值**。<br>模型输出概率 > 0.05 即认为该物质存在。<br>• 调高：减少误报 (False Positive)<br>• 调低：减少漏报 (False Negative) |
| **TOP_N_PEAKS** | `10` | **特征展示数**。<br>在可解释性分析报告中，展示前多少个最重要的特征波长。 |
